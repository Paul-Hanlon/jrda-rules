# Features

## Rules Browser

Browse the full JRDA ruleset organised by section. Each rule is presented clearly with support for navigating directly to a specific section via URL.

## Glossary

A searchable glossary of roller derby terms, with definitions tailored to different reading age groups (7–8, 9–10, 11–12, 13+).

## Quizzes

Topic-based quizzes to test knowledge of the rules. Questions are filtered by reading age and skill level to provide an appropriate challenge.

## Casebook

Real-world scenarios illustrating how rules apply in practice. Each scenario walks through the situation and the correct ruling, helping users build practical understanding.

## Reading Age / Skill Level Selection

Users can select their reading age and skill level via an onboarding dialog or the in-app selector. All content adapts accordingly.

## Support

A support page for users to report issues or flag questions about specific content.
